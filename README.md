## ◈ THE ARCHITECTURE

This repository houses the source code for my personal digital portfolio. It is engineered from the ground up to showcase **Full Stack System Design**, **AI-Native Workflows**, and **Premium Product Execution**. It operates not just as a visual showcase, but as a technical demonstration of modern web engineering.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, GSAP

## ◈ ENGINEERED SYSTEMS

### 1. SmartFlow
A dynamic traffic intersection engine. It replaces standard static timers with deep algorithmic lane-priority scoring to optimize vehicle throughput in real-time.

### 2. RailCascade Mini V2
A highly complex railway traffic coordination environment focused heavily on advanced data structures, scalable routing algorithms, and automated conflict resolution.

### 3. 10Kicks
A highly optimized frontend e-commerce interface showcasing modern web architecture, fluid responsive layouts, and immersive product interaction design.
